# استوديو الإبداع الذكي — Smart Creativity Studio

منصة **PWA** (Progressive Web App) تعمل أوفلاين لإدارة المحتوى الرقمي: رفع الفيديو، استخلاص الصوت **MP3**، حفظ الصور، وتنزيل ملفات الوسائط المباشرة المتاحة من الويب، مع مشغّل داخلي وشريط إجراءات للمشاركة والحذف.

> كل البيانات تُحفظ في **IndexedDB** على جهاز المستخدم — لا يوجد أي رفع إلى خادم.

---

## 🚀 التشغيل

الـ Service Worker يحتاج `https://` أو `localhost`. أبسط طريقة:

```bash
cd creative-studio
python3 -m http.server 8765
# ثم افتح: http://localhost:8765
```

أي خادم ملفات ثابت يكفي (`npx serve`، `php -S localhost:8765`، Nginx…).

### التثبيت على الجهاز
- **Chrome / Edge**: أيقونة التثبيت في شريط العنوان ← "تثبيت" — أو زر «تثبيت التطبيق» داخل الواجهة.
- **Android**: سيظهر «إضافة إلى الشاشة الرئيسية».
- **iOS Safari**: مشاركة ← «إضافة إلى الشاشة الرئيسية».
- بعد تثبيت التطبيق، يمكن اختيار «مشاركة» في المتصفح ثم «استوديو الإبداع الذكي» لإرسال الرابط إلى خانة الرابط داخل التطبيق. الإتاحة تعتمد على دعم المتصفح لـ Web Share Target؛ وتظل روابط صفحات المنصات صفحات وليست ملفات وسائط مباشرة.

## ⚙️ الأقسام

### 1️⃣ الفيديو
سحب وإفلات أو اختيار ملف. يُستخرج منه:
- **صورة مصغّرة** تلقائياً (-canvas من أول إطار)
- المدة والأبعاد (العقد الثابت)
يُحفظ في IndexedDB ويظهر كبطاقة قابلة للتشغيل والمشاركة.

### 2️⃣ استخلاص MP3
```
ملف فيديو/صوت → Web Audio API (فك الترميز) → OfflineAudioContext (تخ mono @ 44.1kHz)
              → lamejs 1.2.1 (ترميز 128 kbps) → Blob audio/mpeg → IndexedDB
```
مع **شريط تقدّم** يعرض كل مرحلة. التحقق من سلامة الملف: يتوقّع الإطار الأول `FF Ex/Fx` أو ترويسة `ID3`.

### 3️⃣ الصور
رفع متعدّد، معاينة مصغّرة، قراءة الأبعاد. جاهزة للمشاركة والحفظ.

### 4️⃣ المخزن المحلي
- تصفية حسب النوع (فيديو / صوت / صور)
- بحث فوري بالاسم
- عداد المساحة المستخدمة (`navigator.storage.estimate()`)

### 5️⃣ روابط الوسائط المباشرة
- يقبل رابط `HTTP(S)` مباشر لملف فيديو أو صوت أو صورة، ويعرض نوعه وحجمه قبل الحفظ.
- تنزيل المتصفح يحتاج أن يسمح خادم الملف بطلبات CORS؛ روابط صفحات Facebook وTikTok وInstagram وغيرها ليست روابط ملفات مباشرة ولا يدعم التطبيق استخراج محتواها.
- الحد الأقصى للملف 100 م.ب. يحفظ الفيديو والصورة بصيغتهما الأصلية، ويحوّل الصوت المدعوم محلياً إلى MP3.
- لا يتجاوز تسجيل الدخول أو DRM أو قيود الوصول، ولا يغيّر جودة الملف؛ الجودة المتاحة يحددها المصدر. تنزيل ملفات الألعاب أو تثبيتها غير مدعوم.

## 🎛️ مشغّل الوسائط
تشغيل/إيقاف، شريط تقدّم قابل للنقر، عرض الزمن، تحكّم بالصوت، زر مشاركة مباشر.
عرض الصوت يتضمن **equalizer متحرك** (يراعي `prefers-reduced-motion`).

## 📤 الشريط الجانبي (الجانب الأيمن — RTL)
يفتح بالنقر على أي بطاقة ويعرض معاينة + بيانات وصفية كاملة:

| الإجراء | السلوك |
|---|---|
| **تشغيل** | يفتح المشغّل الداخلي |
| **مشاركة** | Web Share API مع ملفات؛ fallback للتحميل إن لم يكن مدعوماً |
| **حفظ في المعرض** | ينزّل الملف بالاسم الصحيح عبر `Blob` + `download` |
| **حذف** | يطلب تأكيداً ثم يحذف من IndexedDB |

---

## 🔌 هندسة Offline-First

| المورد | الاستراتيجية |
|---|---|
| هيكل التطبيق | **Cache-first** (يُخزَّن مسبقاً عند التثبيت) |
| التنقّل (navigation) | **Network-first** مع fallback إلى `index.html` |
| ملفات ثابتة | **Cache-first** ثم شبكة ثم cache |
| بيانات المستخدم | **IndexedDB** (لا تُمسح عند التحديث) |
| روابط خارجية | طلب مباشر من المتصفح فقط عند اختيار المستخدم؛ يتطلب CORS من المصدر |

`CACHE_VERSION` في `sw.js` هو مفتاح التنقية — عند تعديل الملفات غيّره إلى إصدار جديد ليتخلص من الكاش القديم.

## 🧪 الاختبارات

```bash
python3 -m http.server 8765 &          # من داخل مجلد المشروع
node tests/e2e.js
```

يغطّي **41 فحصاً**: تسجيل SW، استقبال الرابط من المتصفح، الرفع، استخلاص MP3 (مع التحقق من الـ bytes)، الروابط المباشرة، البحث والفلاتر، المشغّل، الشريط الجانبي، الحفظ بعد إعادة التحميل، **والعمل في وضع عدم الاتصال**، والتأكد من خلوّ الـ console من الأخطاء.

---

## 🔐 الخصوصية والأمان
- لا تُرفع الملفات إلى خادم التطبيق؛ طلب الرابط المباشر يذهب من المتصفح إلى خادم المصدر عند اختيار المستخدم.
- لا يوجد `eval` ولا تتبّع خارجي.
- الروابط الخارجية لا تعمل أوفلاين، وقد يمنعها خادم المصدر أو سياسة CORS.
- `lamejs` محزومة محلياً — لا CDN.
